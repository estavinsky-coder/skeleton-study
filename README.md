# למידת שלד האדם

אתר ללימוד שמות ומיקומים של עצמות הגוף: כרטיסיות, "איפה זה?", "מה זה?", גרירה למקום וחקירה חופשית.
קובץ יחיד (`index.html`) + תמונה (`skeleton.png`), בלי שרת ובלי התקנות. עובד גם בטלפון.

לבדיקה מקומית: `python -m http.server` ואז לפתוח http://localhost:8000
מצב כיול נקודות: להוסיף `?debug` לכתובת.
